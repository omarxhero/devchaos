# Third-Party Licenses

DevChaos builds on the following open-source projects. Their license texts are
reproduced or referenced below. Full license copies live in `vendor-licenses/`.

## blackhole-timer (MIT)

The geodesic black hole shader (`src/shaders/blackhole-port.frag`), the Electron
overlay/break window patterns, and the display-capture-to-texture pipeline are adapted
from https://github.com/cabbagehao/blackhole-timer (MIT). Full text:
`vendor-licenses/blackhole-timer-MIT.txt`.

## ghostty-blackhole (MIT)

Original shader lineage and demo-mode concepts from
https://github.com/s13k/ghostty-blackhole (MIT). The upstream `demo.gif` is
included unchanged at `docs/media/demo.gif` and displayed in the README as the
original effect demo, not a DevChaos recording. Copyright (c) 2026 s13k.
Full text: `vendor-licenses/ghostty-blackhole-MIT.txt`.

## jsfxr (Unlicense / public domain)

Procedural 8-bit sound effects (`src/audio/vendor/sfxr.mjs`) from
https://github.com/loov/jsfxr — dedicated to the public domain via the Unlicense.

## Promptlinter (MIT)

Vague-prompt detection regexes in `src/brain/scorer.js` are inspired by the rule set in
https://github.com/promptlint/promptlinter (MIT).

## npm dependencies

- `electron` (MIT) — application shell
- `jimp` (Apache-2.0) — sprite cutout pipeline at build time only
